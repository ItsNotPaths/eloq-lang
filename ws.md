# eloqc plan

Sections 1–10 of `docs/plan.md` are built. What is left splits into the design decided on
2026-11-19 (workstream D) and the rest of the build (workstream B).

## Workstream D: build the decided design

The decisions are in `docs/design.md`. In short:

- `pending-count`: no `count()` or `capacity()` calls. Tables get `.count` (rows at step
  start) and `.added` (pending adds); capacity is a plain constant.
- `abcont`, `abend-removed-flags`: two kinds of code. An abend stops the step and clears
  pending flags. An abcont skips the failed row and finishes the step. `TABLE_FULL` and
  index out of range are abconts. Undoing a step is the host's own copy.
- `abend-detail`: codes in a fixed array in the state, `abends`, in the order they happen:
  code, line, row, value per entry. The step returns the number of codes. The host sets
  `abends.stop_on_abcont` to make an abcont stop the step like an abend.
- `coercion`: automatic both ways by C rules, no casts; `--coercions` lists each one.
- `index-syntax`: row order, `enemies[target].position`, reads and writes, in lines, values
  and bodies. An index write counts as writing the whole column. Out of range is an abcont;
  in a body or value the callee records it and the step skips the row.
- `pipe-values`: an on-demand value can be a pipe of procs with no destination. No inline
  operator procs (`|- position|`): every step of a pipe is a named proc.
- `whole-array-procs`: no body loops; a foreign proc on a table gets `Table *` once.
- `opaque-strings`: built-in `string` as Odin's `{data, len}`; fixed text is `[N]char`.
- `proc-overloading`, `vector2-procs`: procs share a name when input slot types differ.

Built, except two decided on 2026-11-19, after the rest:

- `pipe-procs`: a proc can be a pipe of procs with no data on either end,
  `length :: |length_squared| |sqrt|`.
- `math-procs`: C math is reserved procs (`|sqrt|`, `|sin|`, `|atan2|`), overloaded for float,
  double and arrays; two-value functions take a struct or array. Expressions have no calls.
  `length` becomes a pipe, `normalize` inline C.
- `inline-c`: a foreign proc with no C name has its C as the indented body, with `input` as
  its parameter. Built.

## Workstream B: build, sections 11 and up

Write sets and section 11 (recompute placement) are built. Every pointer is `restrict`
(decided 2026-11-19), so foreign calls cannot clobber state the compiler holds. Read-only
fields are passed in and hoisted over row loops, and array columns move element by
element; with both, gcc vectorizes every row loop of the test program
(`-fopt-info-vec-all`). Then section 13 (tooling).

Tooling, decided 2026-11-19: reports are plain lines on stdout. Each report is a flag
(`--coercions`, `--access`, `--index-order`, `--log-intermediates`) and `--report` is all of
them. `--format` rewrites the file with tabs and one opener, whichever of `?` and `¿` is used
more; `--upside-down` makes it `¿`.

No parallel lines (decided 2026-11-19): eloq runs on one thread and the host runs states on
its own threads if it wants.
